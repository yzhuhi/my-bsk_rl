bsk_rl.utils.constants: 物理常量和系统默认值定义

此模块集中管理 STIN 仿真中使用的物理常量和默认参数， 避免在代码中硬编码，便于维护和配置。

R_I = B_I × log₂(1 + (p_I × g_I^tr × g_I^rc) / (L_I × N₀ × B_I))

Parameters:

  • tx_power (float) – [W] 发射功率 p_I (Agent 可控)

  • distance (float) – [m] 星间距离

  • max_distance (float | None)

Returns:

传输速率 [bps]，限制在 [1 kbps, 1 Gbps]

Return type:

float
