STIN Task Data

Data system for STIN task offloading and completion tracking.

This module defines the reward calculation for satellite-terrestrial integrated network (STIN) multi-agent reinforcement learning environments.

class STINTaskReward(w_progress: float = 0.0, w_complete: float = 60.0, w_expired: float = 20.0, w_energy: float = 3e-06, w_delay: float = 0.6, w_queue_penalty: float = 0.5, w_slice_drain: float = 0.0, max_queue_size: int = 40, progress_norm_gbits: float = 1.0, global_reward_ratio: float = 0.3, w_utilization: float = 0.5, w_pbrs_queue: float = 0.0, pbrs_gamma: float = 0.99)[source]

Bases: GlobalReward

初始化 STIN 任务奖励计算器。

Parameters:

  • w_progress (float) – 面包屑奖励，每处理 1 Gbits 数据的奖励。

  • w_complete (float) – 任务完成基础奖励（会乘以时延折扣和优先级）。

  • w_expired (float) – 超时惩罚系数（惩罚 = w_expired × priority）。

  • w_energy (float) – 能耗成本（每焦耳扣分）。

  • w_delay (float) – 时延敏感度 [0, 1]。

  • w_queue_penalty (float) – 队列长度惩罚系数。

  • max_queue_size (int) – 队列长度归一化上限。

  • progress_norm_gbits (float) – 面包屑奖励归一化尺度。

  • global_reward_ratio (float) – 全局结果奖励混合比例 [0, 1]。

  • w_utilization (float) – 资源利用率奖励系数。

  • w_pbrs_queue (float) – PBRS 队列势函数系数。

  • pbrs_gamma (float) – PBRS 折扣因子。

  • w_slice_drain (float)

calculate_reward(new_data_dict: dict[str, STINTaskData]) → dict[str, float][source]

计算每个卫星的奖励。

奖励由三类构成： 1) 结果项：完成奖励 / 超时惩罚 2) 成本项：能耗成本 3) 轻量 shaping：队列惩罚、进度、利用率、PBRS（可配置开关）

结果项可按 global_reward_ratio 进行全局混合，促进系统级协同。

Parameters:

Return type:

dict[str, float]
