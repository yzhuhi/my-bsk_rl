computingSatellite_demo_vizard

Vizard Visualization Demo for Lite Computation Satellite

This script demonstrates the 3D visualization of a LiteComputationSatellite constellation using Basilisk’s Vizard tool.

可视化规则（参考 Agile EOS 视频风格）：

  • 任务大小 (markerScale) → 表示数据量（数据越大，标记越大）

  • 任务颜色 (color) → 表示优先级（绿色=低，黄色=中，红色=高）

  • 任务完成后 → 颜色变蓝（通过 mark_task_completed 方法）

Requirements: - Vizard must be downloaded and installed - Set VIZARD_PATH environment variable or modify the path below

Usage:

python computingSatellite_demo_vizard.py

After running, open the generated .bin file in Vizard to view the simulation.
