computingSatellite_demo_vizard_ppt

Vizard Visualization Demo for PPT Presentation (Enhanced)

Features: 1. Task Perception: Green lines indicating task access (Satellite <-> Task). 2. Task Offloading: Yellow lines indicating inter-satellite routing (Satellite <-> Satellite). 3. High Density: 40 Satellites, 500 Tasks for a busy, impressive visual.

Usage:

python computingSatellite_demo_vizard_ppt.py
