stin_viz

STIN Vizard Visualization Script

This script sets up the full STIN environment (CityTaskScenario + ComputationSatellite) and runs a simulation to generate a Vizard visualization file.

Usage:

python stin_viz.py

Output:

./vizard_output/ (contains .bin file for Vizard)

create_viz_env()[source]

Create the STIN environment with Vizard enabled.

run_viz_simulation()[source]

Run the simulation loop.
